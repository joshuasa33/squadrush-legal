Häufige Fragen / FAQ

Käufe wiederherstellen / Restore purchases: Einstellungen → „Käufe wiederherstellen“ (Settings → “Restore purchases”). Einmalige Käufe wie „Keine Werbung“ werden auf jedem Gerät mit demselben Store-Konto wiederhergestellt.

Werbe-Einwilligung ändern / Change ad consent: Einstellungen → „Werbung“ (Settings → “Ads”).

Analyse abschalten / Turn off analytics: Einstellungen → „Analyse“ (Settings → “Analytics”).

Sprache / Language: Einstellungen → Sprachknopf (Settings → language button).
